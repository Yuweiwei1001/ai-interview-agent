## 1. 页面与路由（router.ts）

| 路由 | 页面 | 说明 |
|:---|:---|:---|
| `/login` `/register` | Login/RegisterView | 认证 |
| `/home` | HomeView | 首页入口 |
| `/resumes` `/jds` | ResumesView/JdsView | 简历与 JD 管理 |
| `/knowledge-bases` | KnowledgeBasesView | 知识库管理（库/文档 CRUD + 向量化状态展示） |
| `/interview/start` | InterviewStartView | 选择简历/JD/方向/人格/时长/知识库（可选）→ 启动 |

- 全局路由守卫：`requiresAuth` 且无 accessToken → 跳 `/login`。

## 2. SSE 客户端（utils/sse.ts）

- `connect()`（POST）：启动新面试，**不自动重连**（避免重复创建会话）；
- `connectGet()`（GET）：重连已有流，断线时**指数退避自动重连**（1s→2s→4s→8s→16s，最多 5 次），服务器主动 complete 不重连；
- `parseStream()`：`ReadableStream` 读取 + buffer 按 `\n\n` 切分事件，兼容 `\r\n`，多行 data 拼接；
- `disconnect()`：手动关闭（AbortController + 清重连定时器）。

## 3. 轮询兜底（防 SSE 事件丢失卡死）

InterviewRoomView 内置 **4~5s 周期轮询** `getSession(id)`：

- `waiting_code` → 跳转 CodingRoom（带 currentQuestion）；
- `completed/interrupted` → 停止轮询、展示报告入口；
- 进行中且 `currentQuestion` 变化 → 补齐助手消息（恢复下一题）。

这是历史上"编程题提交后卡在评估中"问题的端到端修复（轮询 + 后端 `current_question` 持久化双保险）。

编码页（CodingRoomView）不轮询，依赖 SSE 连接保活：断线自动重连（见第 2 节）+ 顶栏连接状态灯（已连接/连接中/连接中断重连中）；SSE 事件驱动路由（QUESTION 回面试间 / COMPLETE·REPORT_READY 跳报告页 / WAITING_CODE 展示重试提示）。

## 4. 其他

- `utils/request.ts`：axios 封装，请求带 Bearer Token，401 自动 refresh 重放。
- `stores/auth.ts`：Pinia 认证状态。
- `api/knowledge.ts`：知识库 API 层（库/文档 CRUD）；InterviewStartView 通过下拉选择知识库，随 start 请求传 `knowledgeBaseId`；InterviewRoomView start body 同样携带。
- `api/observability.ts`：观测台 API 层（`getTraceSessions` / `getTraces` / `getUsageSummary`，对应后端 `/api/observability/*`）；ObservabilityView 用 NDataTable + NDrawer + `<details>` 折叠 Prompt/回复全文，agent 名有中文映射。
- `api/eval.ts`：评测 API 层（`listEvalCases` / `startEvalRun` / `getEvalRun` / `runCalibration`，对应后端 `/api/eval/*`）；报告结构全字段强类型（EvalReport/CaseResult/RuleMetrics/JudgeMetrics/CalibrationResult/TimelineEvent），EvalView 依此渲染汇总卡片/校准表/逐用例卡片与时间线。
- `components/CodeEditor.vue`：Monaco Editor 纯编辑器组件（v-model 代码、Java/Python 语法高亮、`bare` 模式深色主题）；运行/提交按钮与结果面板已上提到 CodingRoomView。
- `components/QuestionPanel.vue`：题目 markdown 渲染面板（标题/小节/代码块/列表），编程页左栏。
- `components/CodingResultPanel.vue`：执行结果面板：默认折叠，运行发起/重试提示/错误时自动展开；折叠条显示通过统计或「✓ 运行完成 · 无测试用例」；测试结果/控制台双 tab，运行结束无测试结果时自动切控制台（展示沙箱 stdout 或编译错误）。
- `components/ChatBubble.vue`：对话气泡组件（题目卡片 / 答案 / 思考中状态渲染）。
