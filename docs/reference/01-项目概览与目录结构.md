## 1. 项目概览

### 1.1 项目定位

**ai-interview-agent 是一个面向技术面试场景的智能多 Agent 面试平台**：候选人上传简历（可选 JD）后，系统自动生成面试计划，由多个"面试官 Agent"（技术基础 / 项目经验 / 编码能力）协同完成一场结构化、可持久化恢复的模拟面试，最终输出带多维评分的面试报告与成长对比。

### 1.2 与其他系统的关系

- 从 ThinkVerse 项目移植了大量已验证资产：JWT 双 Token、统一响应/异常体系、SSE 注册表、前端 POST SSE 解析器、AskQuestionTool 的 Human-in-the-Loop 模式、StateGraph 骨架（MysqlSaver + interrupt/resume）等（详见 `docs/superpowers/plans/2026-08-05-ai-interview-agent-mvp.md` 第 6 节）。
- 与 ThinkVerse 的本质差异：本系统用 **StateGraph 多节点编排**（各节点职责单一、条件边控制流转），ThinkVerse 用**单 Agent ReAct 循环**；本系统独有编程题沙箱评估与人格行为策略，ThinkVerse 独有 Langfuse 可观测性与更完整的长期记忆。

## 2. 技术栈

| 层 | 技术 | 版本/说明 |
|:---|:---|:---|
| 语言 | Java | 21 |
| 后端框架 | Spring Boot | 3.5.8（含 starter-web / validation / jdbc / security / **actuator**，actuator 仅为启用 Spring AI Observation 埋点） |
| AI 能力 | Spring AI Alibaba | 1.1.2.0（DashScope Starter + StateGraph graph-core） |
| 大模型 | 通义千问（DashScope） | qwen3.7-max-2026-05-17（出题/评估/计划，需 enable-thinking: true）、qwen-turbo（Coordinator 路由，降本）、text-embedding-v3（知识库向量化） |
| 数据库 | MySQL | 8.0（容器端口 13307，库 `ai_interview`） |
| 向量库 | Elasticsearch | 8.13.4（端口 9200，知识库向量存储，Spring AI ElasticsearchVectorStore） |
| 缓存 | Redis | 7-alpine（端口 6380，预留） |
| ORM | MyBatis | 3.0.4（注解式 Mapper，无 XML） |
| 迁移 | Flyway | 7 个版本化迁移脚本（V7 = llm_trace 观测表） |
| 认证 | JWT | jjwt 0.12.6，双 Token（access 2h / refresh 7d），BCrypt 密码 |
| 文档解析 | Apache Tika | 2.9.2（PDF/DOCX/DOC/TXT → 纯文本） |
| 沙箱 | Docker CLI | `docker run` 硬隔离（network none / read-only / 资源限制），镜像预热 |
| 前端 | Vue 3 + Vite + TS | Naive UI + Monaco Editor + Pinia + vue-router + axios |

### 2.1 依赖管理要点（pom.xml）

- 通过 `<dependencyManagement>` 导入两个 BOM 统一管理版本：`spring-ai-bom 1.1.2` 与 `spring-ai-alibaba-bom 1.1.2.0`。
- 主要依赖源为 Spring Milestones 仓库（Boot 3.5.8 里程碑版本）。
- 关闭了 Spring Security 的自动安全配置（`SecurityAutoConfiguration` + actuator 引入的 `ManagementWebSecurityAutoConfiguration`），只保留 `BCryptPasswordEncoder` 用；认证走自定义 `JwtTokenInterceptor`。
